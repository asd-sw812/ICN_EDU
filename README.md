# The Endless Archive

[게임 실행](https://asd-sw812.github.io/ICN_EDU/)

`game`이 원본 HTML입니다. `main`에 변경을 올리면 GitHub Actions가 이 파일을 `index.html`로 배포합니다.

## 아트 제작 현황

- [x] 탄환덱 4명 이미지: 출전 편성, 덱 목록, 전투 캐릭터 및 공격 연출에 공용 적용
- [x] 공격 연출 개선: 발사 궤적, 명중 섬광과 파편, 화면 진동, 궁극기 캐릭터 컷인
- [ ] 나머지 덱 캐릭터 이미지 제작 및 연결 (전체 성비 남성 1 : 여성 9 목표)
- [ ] 보스 이미지 제작 (Tripo AI의 3D 모델 사용 검토)
- [ ] 전투 배경 제작 (NovelAI)

이미지 경로는 `assets/characters/<캐릭터 ID>.png`이며 `game`의 `CHARACTER_IMAGES`에서 연결합니다. 탄환덱 슬롯은 권총, 기관단총, 저격총, 중기관총 순서입니다. 원본 NovelAI PNG와 메타데이터를 보존했습니다.

현재 보스와 배경은 기존 벡터 아트입니다. 3D 모델과 새 배경은 아직 제작하지 않았습니다.

화려한 연출이 부담스러우면 전투 화면 상단의 **연출: 간소**를 선택할 수 있습니다. 운영체제의 모션 감소 설정도 첫 실행 시 반영됩니다.
