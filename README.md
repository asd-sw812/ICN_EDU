# The Endless Archive

## 전투 정보와 자원 간소화

아군 카드를 크게 표시하고 체력, SP, 궁극기 에너지를 우선 배치합니다. 현재 행동과 지원 대상은 별도의 한글 배지로 표시합니다. 작은 가로 화면에서도 아군 카드 4장을 유지하며 스킬 설명은 선택할 때 펼칩니다.

탄환, 전류, 저장·기록·축적 피해를 사용하는 캐릭터 12명만 개인 자원을 유지합니다. 그 외 84명의 개인 자원은 획득·소비·HUD에서 제거했습니다. 이름만 바꾼 전술 스택도 없습니다. 광휘·광채, 나무 성장, 풍력은 공용 상태로 한 번만 표시하며 물결은 궁극기 에너지 구간을 사용합니다.

보조 스택을 제거한 스킬은 기본 효과가 고정됩니다. 기존 소비량 계수는 스킬 2의 고정 강도 1~2, 궁극기의 고정 강도 3으로 계산하며, 해당 숫자는 별도 게이지나 보유 자원이 아닙니다. 체력소모덱의 궁극기는 현재 잃은 체력을 사용하고 처형 기준은 남은 HP 25%로 고정했습니다. 스킬덱은 SP·에너지 지원으로 재구성했습니다. 따라서 보조 자원을 축적하는 이전 버전과 밸런스가 달라집니다.

검증: `node tests/game-regression.cjs` (24개 덱, 96명, 288개 스킬 미리보기 및 미사용 자원 제거 검사).

[게임 실행](https://asd-sw812.github.io/ICN_EDU/)

`game`이 원본 HTML입니다. `main`에 변경을 올리면 GitHub Actions가 이 파일을 `index.html`로 배포합니다.

이미지 경로는 `assets/characters/<캐릭터 ID>-ld-v4.webp`이며 `game`의 `CHARACTER_IMAGES`에서 연결합니다. `assets/characters/manifest.json`에 캐릭터별 콘셉트와 시드를 기록했습니다. 덱 목록의 작은 이미지는 지연 로딩합니다.

덱 키워드만 공유하고 각 캐릭터의 직업, 소품, 장면은 다르게 구성했습니다. 예를 들어 독덱은 연금술사·염료사·조향사·균류 채집가, 방어덱은 방화문 검사원·제본가·보존 처리사·댐 관리인입니다. 탄환덱은 탐정·항구 밀수꾼·야생동물 사진가·사격장 관리인의 고전적인 총기와 복장으로 구성했습니다. SF 요소는 전기덱에만 사용했습니다. 원본 NovelAI PNG와 생성 메타데이터는 별도 원본 묶음에 보존했습니다.

전투 화면의 3D 모델 표시는 제거했습니다. 제작된 GLB 원본과 작업 기록은 assets/models/characters에 보관합니다.

현재 보스와 배경은 기존 벡터 아트입니다. 새 보스 모델과 배경은 아직 제작하지 않았습니다.

화려한 연출이 부담스러우면 전투 화면 상단의 **연출: 간소**를 선택할 수 있습니다. 운영체제의 모션 감소 설정도 첫 실행 시 반영됩니다.

전투 캐릭터는 연결된 뒷모습 2D 리그로 움직이고, 전투 슬롯은 편성 이미지를 재사용합니다. VFX는 실제 24개 덱의 메커니즘과 피해·지원 이벤트를 기준으로 차별화하며, 공통 덱 프리셋에 96개 캐릭터 Modifier와 스킬 Modifier를 합성합니다. 상세 설계는 [VFX-DESIGN.md](assets/battle/VFX-DESIGN.md)에 기록합니다.

여성으로 교체한 10명은 `native-cubism.js`가 Cubism Editor 5.3에서 실제 내보낸 메시와 파라미터 키폼을 렌더링합니다. 기본 호흡과 일부 머리·옷자락·팔의 작은 변형을 연결했으며, 큰 각도의 몸 회전이나 완전한 무기 타격 동작은 아직 제작하지 않았습니다. 모델은 `assets/battle/live2d/<ID>/`에 있습니다. 다른 캐릭터는 기존 2D 리그를 유지합니다. 회복 캐릭터는 머리부터 발까지 보이도록 후면 구도를 수정했고, 신문 배달원은 신발 주변의 잔여 조각을 정리했습니다. 원본 PNG·메타데이터·PSD·편집 가능한 CMO3는 로컬 `outputs/female-revisions/`에 보관합니다.

공격 VFX는 16종의 질감 있는 스프라이트를 전경·중경·후경으로 합성합니다. 시전 입자, 덱별 주 타격, 짧은 섬광, 지연 파편, 잔광을 서로 다른 시간에 생성하며, 미리 생성한 텍스처 시트로 첫 공격의 생성 비용을 줄입니다.

전투 UI는 작은 가로 화면에서 실제 화면 너비와 높이를 기준으로 크기를 조절합니다. 아군 정보는 얇은 하단 카드로 표시하며, 보스 체력과 다음 행동은 바로 보이고 능력치·상태는 보스 상세에서 펼칩니다. 캐릭터를 누르면 스킬의 핵심 효과를 볼 수 있고, 상세 수치와 조건은 개별적으로 펼칠 수 있습니다. 96명의 후면 이미지에 표시 범위를 저장하여 투명 여백의 차이가 크기와 발 위치를 바꾸지 않도록 했습니다. 공격·지원·피격·궁극기는 서로 다른 작은 리그 변형을 사용하며 움직임 끄기 설정을 따릅니다.

반격·초과 회복의 피해 단위를 수정하고 덱별 피해를 조정했습니다. 변경 후 기록은 별도 키에 저장하며 기존 기록을 삭제하지 않습니다. 검증 방법과 자동 전투의 한계는 [전투 조정 검증](tests/BALANCE-20261007.md)에 기록했습니다.


## AV 전투 (2026-10-08)

사이클 대신 연속 행동 게이지를 사용합니다. 기본 대기 AV는 `10000 / SPD`이며 속도 변경과 행동 당김이 남은 게이지에 반영됩니다. 누적 피해 모드는 350AV에 종료하고, 속전 토벌은 HP 120,000 보스를 처치한 최소 AV를 기록합니다. 같은 AV이면 아군 행동 횟수가 적은 기록을 우선합니다. 성장, 강화, 버프 및 지속 피해도 AV로 계산합니다. 추가 공격과 반격은 별도 AV를 소비하지 않습니다.

전투 종료 및 정산 버튼으로 누적 피해를 조기 정산할 수 있습니다. AV 기록은 기존 기록과 별도로 보관합니다. [AV 검증 결과](tests/BALANCE-20261008-AV.md)를 참고하세요.
