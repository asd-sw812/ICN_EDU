# 실제 전투 메커니즘 기반 VFX

근거: `game`의 `DECKS`, `CHARACTER_REVISIONS`, `NEW_MENTAL_DECKS`, `SUPPORT_ACTIONS`, `useSkill`, `damage`, `takeDamage`, 패시브 및 사이클 처리. 20개 기본 덱과 4개 정신 덱을 모두 대조했다. 설명에만 있고 구현되지 않은 행동 당김이나 에너지 훔치기 등은 VFX로 새로 추가하지 않는다.

## 구조

`덱 프리셋 + 캐릭터 Modifier + 스킬 Modifier + 실제 전투 이벤트/상태 스냅샷`. 프리셋 24개, 캐릭터 Modifier 96개, 스킬 Modifier 3개를 공유 렌더러로 합성한다. 캐릭터별 방향·타점 분포·크기·속도·준비 모션을 변형하고, 실제 역할 차이는 발생한 피해·지원 이벤트와 자원·강화 상태로 구분한다.

타격 수는 실제 피해 이벤트와 1:1 대응한다. 연출상의 추가 피해·상태이상·능력은 만들지 않는다. 지원 판정이 피해를 차단한 스킬은 공격 VFX를 내지 않는다. 보호막/회복/버프는 실제 발생 대상에 표시한다. 보스 공격은 아군 덱 공격으로 바꾸지 않고 중립 피격을 사용한다. 반격은 보스의 피격 이벤트 뒤 짧은 정적 후 실제 반격 발동자의 프리셋으로 역방향 방출한다.

상태 잔여 표시는 실제 상태가 사라지면 즉시 사라진다. 큰 자원은 8개 이하의 밀도로 압축해서 표시하고 기존 숫자 UI를 유지한다. VFX 전용 난수는 전투 `Math.random`과 독립적이다. 타이밍·피해 계산·확률·턴·스킬 계수는 변경하지 않는다. 저사양 및 Canvas2D 대체 렌더러에서도 같은 프리셋을 사용한다.

## 탄환덱 (`bullet`)

실제 설명: [탄환]을 1스킬로 수급하고, 한 번에 많이 소모할수록 스킬/궁극기가 강해진다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 개인 탄창 수급·소비 |
| 공격 리듬 | 실제 탄환 타수의 짧은 점사 |
| 파티클 형태 | 집중된 에너지 파열·불규칙 탄피 |
| 이동 방식 | 수평 관통 |
| 메인 타격 | 작은 집중점 |
| 피격 효과 | 짧은 반동 |
| 잔여 효과 | 탄피 낙하 |
| 캐릭터 움직임 | shot |
| 강한 공격의 요소 | 소비량에 따른 압축 관통 |
| 구별되는 특징 | 탄창에서 이어지는 일직선 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `bullet_0` | 집중 탄창 | 한 번에 탄환 5발 이상 소비하면 다음 공격의 치명타 확률이 크게 오른다. |
| `bullet_1` | 탄환 공급 | 아군이 탄환을 4발 이상 소비하면 자신의 탄환을 1발 회복한다. |
| `bullet_2` | 좁은 관통 | 자신의 탄환이 가득 차 있으면 방어 관통이 증가한다. |
| `bullet_3` | 탄창 보호 | 보호막이 있는 동안 1스킬 사용 시 탄환을 1발 추가 획득한다. |

## 중독덱 (`poison`)

실제 설명: [중독]은 개별 지속시간을 가지며 최대 3개. 중독3을 [맹독]으로 바꾸고 [독 폭발]으로 즉시 터뜨린다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 중독/맹독 유지·전환·결산 |
| 공격 리듬 | 부여 후 정체, 결산 시 수축 |
| 파티클 형태 | 덩어리 안개 |
| 이동 방식 | 느린 부유·중심 수렴 |
| 메인 타격 | 결산 응축 |
| 피격 효과 | 탁한 분산 |
| 잔여 효과 | 실제 중독 수의 군집 |
| 캐릭터 움직임 | cast |
| 강한 공격의 요소 | 맹독층과 결산 와류 |
| 구별되는 특징 | 여러 안개 군집이 소거됨 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `poison_0` | 독 결산 | 맹독이 존재할 때 자신의 [독 폭발] 피해가 증가한다. |
| `poison_1` | 중독 전환 | 중독을 3턴으로 부여할 때 낮은 확률로 중독을 하나 더 부여한다. |
| `poison_2` | 기간 유지 | 독 지속시간을 연장할 때 자신의 에너지를 추가 회복한다. |
| `poison_3` | 독 반응 회복 | 중독/맹독 피해가 발생하면 가장 체력이 낮은 아군을 소량 회복한다. |

## 반격덱 (`counter`)

실제 설명: 보호막으로 버티고 피격 시 반격. 받은 피해 일부를 저장해 공격과 함께 되돌려준다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 개인 저장 피해·보호막·피격 반격 |
| 공격 리듬 | 받은 타격 뒤 짧은 정적과 반전 |
| 파티클 형태 | 각진 방벽·쐐기 |
| 이동 방식 | 방어면에서 역방향 방출 |
| 메인 타격 | 역류 쐐기 |
| 피격 효과 | 방벽 압축 |
| 잔여 효과 | 보호막 조각 |
| 캐릭터 움직임 | brace |
| 강한 공격의 요소 | 실제 저장량을 압력으로 환산 |
| 구별되는 특징 | 피격 방향을 되돌림 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `counter_0` | 저장 피해 응수 | 반격이 발동할 때마다 자신의 방어력이 상승한다. |
| `counter_1` | 반격 지원 | 아군의 반격이 발생하면 자신도 낮은 피해의 추가타를 가한다. |
| `counter_2` | 피해 기록 | 피격 피해를 저장할 때 저장량이 증가한다. |
| `counter_3` | 방벽 재생 | 보호막이 파괴되면 작은 보호막을 다시 얻는다. |

## 추가공격덱 (`follow`)

실제 설명: 조건 충족과 스택 축적으로 추가공격을 발생. 자원을 모은 뒤 한 번에 연속 추격을 쏟아낸다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 개인 추격 자원·실제 추가타 |
| 공격 리듬 | 실제 타수를 연결한 교차 리듬 |
| 파티클 형태 | 대각 절개 |
| 이동 방식 | 이전 타점에서 다음 타점 |
| 메인 타격 | 엇갈린 절개 |
| 피격 효과 | 연결된 타점 |
| 잔여 효과 | 끊어지는 작은 궤적 |
| 캐릭터 움직임 | melee |
| 강한 공격의 요소 | 실제 추가타만 후속 절개 |
| 구별되는 특징 | 서로 이어지는 교차선 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `follow_0` | 연속 추격 | 자신이 1스킬을 사용하면 추가공격 확률이 일시적으로 상승한다. |
| `follow_1` | 취기 후속 | 추가공격이 발생할 때 자신의 [취기]를 1 획득한다. |
| `follow_2` | 확률 난입 | 다른 아군이 2스킬을 사용하면 [난입]을 1 획득한다. |
| `follow_3` | 전의 보호 | 피격 후 살아남으면 [전의]를 1 획득한다. |

## 빙결덱 (`freeze`)

실제 설명: [한기]가 속도를 낮추고 5스택이면 [빙결]. 빙결은 행동 불가지만 현실피해를 받으면 풀린다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 한기 5→빙결·현실피해 해제/방지 |
| 공격 리듬 | 쌓임→정지→해제 파편 |
| 파티클 형태 | 세로 결정 |
| 이동 방식 | 아래에서 솟아 정착 |
| 메인 타격 | 좁은 결정 열 |
| 피격 효과 | 빙결 때 외곽 잠금 |
| 잔여 효과 | 실제 한기·빙결 표시 |
| 캐릭터 움직임 | cast |
| 강한 공격의 요소 | 빙결 생성/해제에만 격자/파편 |
| 구별되는 특징 | 정지된 뾰족한 외곽 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `freeze_0` | 빙결 생성 | 적이 빙결될 때 즉시 추가 현실피해를 준다. |
| `freeze_1` | 속도 저하 | 한기를 부여할 때 일정 확률로 속도 감소를 추가한다. |
| `freeze_2` | 해제 방지 | 빙결이 현실피해로 풀리지 않고 유지되면 [태엽]을 1 획득한다. |
| `freeze_3` | 피격 한기 | 자신의 보호막이 있는 동안 피격 시 한기 1을 추가 부여한다. |

## 흡혈덱 (`lifesteal`)

실제 설명: 공격력 비례 피해와 흡혈을 반복. 공격이 곧 회복이며 초과 회복도 공격 자원으로 바뀐다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 피해→흡혈·초과회복 피해 전환 |
| 공격 리듬 | 공격 후 실제 회복 방향으로 귀환 |
| 파티클 형태 | 가는 생명선 |
| 이동 방식 | 적→회복 대상 |
| 메인 타격 | 갈고리 곡선 |
| 피격 효과 | 얇은 수축 |
| 잔여 효과 | 회복 대상에 소실 |
| 캐릭터 움직임 | draw |
| 강한 공격의 요소 | 초과회복 추가 피해도 실제 이벤트 |
| 구별되는 특징 | 회복 시 방향이 뒤집힘 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `lifesteal_0` | 초과 회복 전환 | 자신의 HP가 가득 찬 상태에서 흡혈하면 초과 회복 일부를 추가 피해로 전환한다. |
| `lifesteal_1` | 연구 지원 | 아군이 흡혈로 회복할 때 [연구]를 1 획득한다. |
| `lifesteal_2` | 취약 흡혈 | 취약 상태의 적을 공격하면 자신의 [저주]를 1 획득한다. |
| `lifesteal_3` | 긴급 회복 | 아군 HP가 낮아지면 한 전투에 한 번 즉시 회복한다. |

## 분산피해덱 (`bounce`)

실제 설명: [바운스]가 적 수에 따라 분산되지만, 단일 보스전에서는 모든 타격이 한 대상에 집중된다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 한 보스에 바운스 다단 집중 |
| 공격 리듬 | 실제 타수만 왕복 |
| 파티클 형태 | 굴절 결정·분열된 에너지 꼬리 |
| 이동 방식 | 각 타점 바깥→같은 보스로 복귀 |
| 메인 타격 | 각진 왕복 |
| 피격 효과 | 타마다 다른 반사축 |
| 잔여 효과 | 외곽에 짧은 잔향 |
| 캐릭터 움직임 | cast |
| 강한 공격의 요소 | 실제 타수만 경로 연장 |
| 구별되는 특징 | 보스 외곽을 왕복 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `bounce_0` | 연속 잔향 | 같은 대상에게 바운스가 연속 명중할수록 자신의 [잔향]이 쌓인다. |
| `bounce_1` | 치명 반사 | 바운스 공격이 치명타면 [패]를 1 획득한다. |
| `bounce_2` | 횟수 지원 | 바운스 횟수가 5회 이상이면 [환각]을 1 획득한다. |
| `bounce_3` | 타수 회복 | 바운스가 4회 이상 발생하면 가장 체력이 낮은 아군을 소량 회복한다. |

## 체력소모덱 (`hp`)

실제 설명: 자신의 체력을 깎아 최대 체력 비례 정신피해를 강화. 낮은 HP 자체가 공격 자원이 된다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 개인 HP 소모·희생량 소비·최대HP 계수 |
| 공격 리듬 | 몸에서 빠져나가 한 점에 집중 |
| 파티클 형태 | 응축된 섬유 흐름·긴 에너지 파열 |
| 이동 방식 | 실제 소모 자원→적 |
| 메인 타격 | 세로 희생 창 |
| 피격 효과 | 좁은 압력 |
| 잔여 효과 | 사용자에게 빈 실 |
| 캐릭터 움직임 | draw |
| 강한 공격의 요소 | 실제 HP/희생량 소비에만 변환선 |
| 구별되는 특징 | 사용자에서 에너지가 빠짐 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|
| `hp_0` | 희생 폭딜 | 자발적으로 잃은 HP가 많을수록 자신의 공격력이 증가한다. |
| `hp_1` | 최대HP 지원 | 자신의 HP가 50% 이하일 때 [과부하]를 1 획득한다. |
| `hp_2` | 저체력 버프 | 아군이 자발적으로 HP를 소모하면 [공명]을 1 획득한다. |
| `hp_3` | 윤회 보호 | 체력을 잃을 때 [귀향]을 얻고, 누적량에 따라 보호막을 얻는다. |

## 신속덱 (`speed`)

실제 설명: 속도가 높을수록 공격력이 상승. 궁극기와 지원기로 일회용 [회피]를 얻어 공격을 흘린다.

| 항목 | 설계 |
|---|---|
| 핵심 메커니즘 | 속도 계수·실제 회피 |
| 공격 리듬 | 짧고 빠른 일격 |
| 파티클 형태 | 긴 수평 잔상 |
| 이동 방식 | 좁은 직진 |
| 메인 타격 | 수평 가속선 |
| 피격 효과 | 짧은 옆밀림 |
| 잔여 효과 | 짧은 잔상 |
| 캐릭터 움직임 | dash |
| 강한 공격의 요소 | 실제 회피 이벤트는 옆으로 이탈 |
| 구별되는 특징 | 수평의 짧은 시간축 |

| 캐릭터 | 공통 프리셋 위의 변형 | 실제 패시브 설명 |
|---|---|---|

## 광휘덱 (`radiance`)

## 텍스처와 레이어 구성 (2026-10-05)

독립 WebGL 배치 렌더러를 유지한다. `particle-atlas.png`는 256px 타일 16개를 묶은 1024px RGBA 시트이며, `makeAtlas()`의 노이즈·균열·섬유·굴절 계산으로 생성한다. 런타임은 시트를 먼저 로드하고 실패 시 같은 생성기로 대체한다. 파편과 결정은 단색 기본 도형 대신 불규칙 외곽과 내부 균열/면의 명암을 가진다.

시전 중 수렴 입자와 이동 잔상 → 타격 시 55ms 핵심 섬광과 덱별 주 효과 → 25ms 뒤 깨진 압력 가장자리 → 70ms 뒤 중간 파편 → 130ms 뒤 잔류 입자가 시작된다. 입자마다 추가 딜레이·크기·방향·속도·수명·회전·가속도·감속·투명도가 다르다. 잔류 입자는 약 0.65–1.25초 동안 흩어진다. 이 단계들은 실제 피해 이벤트 하나의 시각적 하위 레이어이며 추가 피해가 아니다.

후경의 느린 연기/먼지, 중경의 주 효과, 빠르고 큰 전경 파편을 세 깊이로 합성한다. 일반 알파와 additive를 조합하며 WebGL은 최대 6회 배치 드로우한다. 전체 화면 Blur는 사용하지 않는다. Canvas2D는 같은 시트의 색상 캐시와 UI 마스크를 사용한다. 기존 간소 옵션은 입자 예산을 줄이고 흔들림을 생략한다. 리셋/탭 숨김/컨텍스트 손실 시 예약 레이어와 잔상을 함께 제거한다.
