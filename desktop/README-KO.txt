The Endless Archive — Windows 오프라인판

실행: ICN_EDU-Offline-Windows-x64.exe를 더블클릭하세요.
Windows 10/11 64비트용입니다. 설치, 인터넷, 별도 브라우저가 필요하지 않습니다.
첫 실행에는 내부 파일을 임시 폴더에 푸는 시간이 조금 걸릴 수 있습니다.
F11: 전체 화면 전환. 창의 X: 종료.

최고 기록과 설정은 같은 Windows 사용자 계정의 앱 데이터에 저장됩니다.
EXE를 다른 폴더로 옮겨도 같은 계정에서는 기록을 유지합니다.
웹브라우저의 기존 기록과 EXE 기록은 별도로 저장됩니다.
다른 노트북/다른 Windows 계정에서는 기록이 공유되지 않습니다.

이 파일은 빌드 시점의 게임 사본입니다. 웹페이지가 수정되어도 자동 업데이트되지 않습니다.
새 버전은 저장소의 Build Windows offline EXE 실행 결과에서 받을 수 있습니다.
패키지에 포함된 SHA256SUMS.txt는 완성 EXE의 SHA-256 값입니다.
