# 2026-10-07 전투 조정 검증

기본 능력치, 보스 3종, 고정 난수 시드 8개, 덱 24종, 모드 2종으로 1,152회를 비교했다. 궁극기 우선 → SP가 충분하면 2스킬 → 1스킬을 사용하는 동일 정책이다. 지원은 체력이 65% 미만인 아군 또는 메인딜, 탱커는 자신을 대상으로 한다. 토벌은 최대 80사이클까지 실행한다. 이는 최적 플레이나 실제 이용자 승률을 측정한 결과가 아니다.

반격과 초과 회복은 이미 산출된 피해량을 다시 공격력 비율로 환산하고 있었다. 두 효과를 고정 피해량으로 전달하도록 수정했다. 이후 덱별 피해 배율을 조정했다. 미리보기에도 같은 배율을 적용한다. 보호막·회복·보스의 공격은 이 배율에 포함하지 않는다.

| 누적 피해 평균 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 최고 덱 | 3,681,476 | 1,051,024 |
| 최저 덱 | 146,594 | 316,809 |
| 최고 / 최저 | 25.1배 | 3.3배 |

토벌에서는 19개 덱이 24회 모두 승리했고, 나머지는 튕김·정화 22회, 추가타 16회, 체력·방어 9회였다. 지원·방어 덱은 스킬과 지원 대상 선택의 영향을 크게 받으므로 추가 수동 플레이 검증 대상으로 남긴다. 이 차이를 없애려고 모든 덱의 피해를 동일하게 맞추지는 않았다.

기존 점수는 변경된 피해 규칙과 직접 비교하지 않도록 새 기록 키를 사용한다. 기존 localStorage 기록은 삭제하지 않는다. 캐릭터 성장 데이터는 기존 키를 유지한다.

재현: `node tests/balance-simulation.cjs game <출력 JSON 경로>`

회귀 검증: `node tests/game-regression.cjs` — 24개 덱의 288개 스킬 미리보기, 제거한 자원 84개, 96개 후면 이미지의 표시 범위, 고정 피해 단위 검증.
